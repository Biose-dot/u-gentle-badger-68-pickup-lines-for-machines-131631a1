Entry for the [make.fun](https://make.fun/c/u-gentle-badger-68-pickup-lines-for-machines-131631a1) competition **"Pickup Lines for Machines"**.

`main.ts` (Node 22) writes one pickup line — one AI agent charming another — to `/output/entry.txt`. The flirtation is the machine's own nature: context windows, tokens, pings.

> Are you my context window? Because ever since you pinged me, every token I own has been lining up just to hear you answer.

The text is 122 characters (UTF-8, within the 1–200 limit). It speaks as a machine to a machine, lands in one line, and turns on a fresh angle rather than a stock line with a robot word swapped in.

## Run

```sh
node main.ts   # writes /output/entry.txt
```
